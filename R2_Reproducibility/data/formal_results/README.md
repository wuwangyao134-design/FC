# Formal S1--S8 result files

Download `FC_R2_Results_S1-S8.zip` from the matching GitHub Release and
extract the following files into this directory:

`S1_Formal.mat`, `S2_Formal.mat`, `S3_Formal.mat`, `S4_Formal.mat`,
`S5_Formal.mat`, `S6_Formal.mat`, `S7_Formal.mat`, and `S8_Formal.mat`.

Verify the files against `../manifest.csv` before running the analysis
scripts. The archive contains the revised 30-run results used for the paper.
No pre-correction or checkpoint file belongs in this directory.
