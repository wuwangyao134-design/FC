# MODDPG implementation audit

This directory contains numerical training summaries for the formal S1--S8
results and a compact comparison between the corrected S2 implementation and
a retained pre-correction record.

The pre-correction raw file and the response-letter diagnostic figures are
distributed separately in `FC_R2_MODDPG_Audit.zip`. The file
`S2_PreCorrection_NotUsedInManuscript.mat` is historical audit evidence only
and was not used to calculate any revised-manuscript result.
